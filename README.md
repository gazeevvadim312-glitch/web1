# Food Construct — лабораторная работа №1

Простой проект: главная страница сайта компании «Food Construct» — доставка бизнес-ланчей в Москве.

Структура проекта:

- index.html — главная страница (семантический HTML, соответствие требованиям лабораторной работы);
- styles/style.css — стили страницы (использован шрифт Montserrat);
- images/hero.jpg — заглушка для изображения (замените на реальное изображение при необходимости).

Требования выполнены:

- Использованы указанные теги: header, nav, main, section, footer, h1, h2, table и т.д.;
- Подключён шрифт Montserrat (weights 400, 500, 600, 700);
- Универсальный селектор * с box-sizing, margin:0, padding:0;
- Стили для блоков, текста, таблицы, изображений, ссылок и футера согласно заданию;
- Контент выровнен по центру, максимальная ширина ~1200px;
- Файлы готовы к проверке валидности (W3C) и проверке на htmlhint.

Как использовать:

1. Клонируйте репозиторий.
2. Поместите изображение в images/hero.jpg (или оставьте заглушку).
3. Откройте index.html в браузере.
